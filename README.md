# 🎮 Rock, Paper, Scissors

A simple Rock, Paper, Scissors game developed in Python as a practice project.

# 📌 About the project

This program allows the user to play Rock, Paper, Scissors against the computer.

The computer randomly chooses one of the three options, and the program determines the result of the game.

# 🧠 Concepts practiced

- User input with "input()"
- Output with "print()"
- Conditional statements ("if", "elif", "else")
- Lists
- String manipulation with ".lower()"
- Logical operators
- The "random" module
- "random.choice()"
- Comparison operators

# 🎯 Purpose

This project was created as an introductory practice in Python and programming logic, applying basic programming concepts to a simple interactive game.
